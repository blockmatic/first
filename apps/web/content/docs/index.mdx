FIRST is a spec-to-code factory: shared language between agents and domain experts, product and system design before code. This site publishes the essays and operational specs. The git repository is the source of truth.

- [Development](/docs/development) — how maintainers work in this monorepo
- [Packaging](/docs/packaging) — what adopters copy, what they edit, what they skip
- [Articles](/articles) — human essays
- [Spec](/spec) — operational specs (factory `principles/`; agents use `/f-*`)

Install the skill with `npx skills add blockmatic/first`. Point root `AGENTS.md` at `_first/`.
