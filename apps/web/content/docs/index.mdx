FIRST is a portable pack of markdown files. This site publishes the essays and operational templates. The git repository is the source of truth.

- [Development](/docs/development) — how maintainers work in this monorepo
- [Packaging](/docs/packaging) — what adopters copy, what they edit, what they skip
- [Articles](/articles) — human essays
- [Spec](/spec) — operational templates

Do not install a FIRST skill. Point root `AGENTS.md` at `_first/`.
