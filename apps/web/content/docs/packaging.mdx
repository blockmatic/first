Canonical layout lives in [`_first/maintainers/PACKAGING.md`](https://github.com/blockmatic/first/blob/main/_first/maintainers/PACKAGING.md). Summary for humans:

## Install

```bash
npx skills add blockmatic/first
```

That copies `/f` (station skills plus `/f-ai-expert`) into the agent skills directory. Refresh later with the same command. Instance files are never part of that install.

## Copy

Into `_first/` at the adopting repository root:

- `AGENTS.md`
- `ABOUT.md`
- `templates/` — copy a template only for stations listed as In
- `README.md` if you want the human door

Create `FIRST.md`. Merge a pointer into existing root `AGENTS.md`. Do not overwrite that file.

## Skip

- `principles/` — live in `/f-*` `references/spec.md`; this factory keeps them for `/spec`
- `articles/` — this site already publishes them
- `instance/` — this repository’s dogfood overlays
- `maintainers/` — factory evolution notes
- `packages/validate` — source-tree validator, not an adopter tool

## Edit vs replace

| File | Who | Update from upstream |
| --- | --- | --- |
| `_first/AGENTS.md`, `ABOUT.md`, `templates/` | User copies; maintainer authors | Replace after reviewing the diff |
| `.agents/skills/f/` | User installs | Refresh via the skills CLI |
| `_first/FIRST.md`, opted-in station files | User edits | Never overwrite |
| Root `AGENTS.md` | User merges a pointer | Never overwrite the rest |

Absent files beat empty stubs. Do not generate twelve empty station files.

## Basilic

[basilic](https://github.com/blockmatic/basilic) is the first external adopter: it installs `/f`, vendors the user pack, and keeps basilic-specific overlays under `_first/basilic/`.
